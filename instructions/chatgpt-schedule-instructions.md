# Scheduled curation handoff

This is a reference shape only. Onboarding generates the actual instruction from the reader's saved frequency, local time, and timezone. Lasting editorial rules belong in the reader's Markdown constitution and should not be duplicated here.

For each scheduled run, read my Curiofold editorial brief first. It contains my constitution and current curation context. Search widely, keep the candidate list internal, and submit only the complete final edition with `create_daily_edition`. If an edition for the scheduled publication date already exists, leave it unchanged. Return the edition link.

Create or update one recurring ChatGPT task for the schedule supplied by onboarding. If a Curiofold task already exists, update it instead of creating a duplicate.
