# Roadmap

The direction is provisional and should follow actual use by the owner and early friends.

The [reading backlog](BACKLOG.md) records the 28 October 2026 follow-up to the personal-newspaper experiment: prototype a durable link collection with three commitment levels and dormant candidates together with a small front page and optional inside pages. These two improvements should ship together after validation. It also preserves the personal-notebook, agent-capability, source-access, and demand-aware curation ideas; source access and automatic pausing remain uncertain and deferred. This backlog describes proposed work, not deployed functionality.

The [announcement readiness plan](ANNOUNCEMENT_PLAN.md) proposes the next launch scope: private user editions, signup, configurable editorial settings, history-aware curation, intentional discovery, and a manageable reading rhythm. Branding changes remain deferred.

## v1 — Personal magazine (current)

- Publish complete scheduled editions through one authenticated API.
- Read the latest edition, browse the archive and track reading locally.
- Operate the product personally and refine the editorial experience from real use.

## v2 — Multi-user curation

- Landing page, sign-up and onboarding-lite.
- Each user owns a magazine, API credentials and dated issues.
- Persist reading state and lightweight feedback for the recommender.
- Invite friends and support socially sourced discovery/recommendations.

## v3 — Agent platform

- Guided onboarding for sources, interests, limits and wellbeing priorities.
- Agents collect, deduplicate, rank and compose editions into the existing publishing contract.
- Bring-your-own subscription/API-key options alongside managed inference credits.
- Add billing only after usage patterns and inference costs are understood.

Across every version: protect the finite-edition idea, link people back to original work, optimise for judgment and wellbeing rather than time-on-site, and keep decisions reversible while the product is being learned.
